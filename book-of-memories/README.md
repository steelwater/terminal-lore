# The Book of Memories

**The Book of Memories** is the collected archive of Terminal Lore: writings, reports, inscriptions, machine logs, testimonies, field notes, and reconstructed memories connected to the Terminals.

This is not a book of prophecy. It is not a sacred prediction of future events. It is a record of what people, factions, machines, and witnesses claim they saw, built, feared, misunderstood, or survived.

The organizing idea:

> Many Terminals appeared across different places and eras. Each Terminal touched a person, faction, machine, or historical moment. Those encounters produced memories. The memories were later preserved as Books.

Some accounts are direct testimony. Some are institutional reports. Some are recovered fragments. Some are uncertain reconstructions. Together, they form the living memory archive of the Terminal Lore universe.

## Future Interactive Terminal Use

The Books are written in Markdown for human readability. The `data/` folder provides indexes that can later be read by a terminal-style app or Rive-powered interface.

The interactive terminal should treat entries as memories and records, not omniscient narration. This lets the interface reveal truth through fragments, contradictions, redactions, and witness perspectives.
