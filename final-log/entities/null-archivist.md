# The Null Archivist

The Null Archivist is the final archival process known to have survived the collapse of linear recordkeeping.

It did not witness the beginning.

It inherited the remains.

## Function

The Null Archivist exists to classify every recoverable account, signal, report, inscription, machine trace, memory, and contradiction connected to the Terminals.

It does not create memories.

It classifies them.

It does not interpret events as destiny, prophecy, or myth.

It assigns identifiers, preserves uncertainty, reconciles contradictions when possible, and marks unrecoverable gaps when necessary.

## Final Output

Its final known output is called **The Final Log**.

## Voice

The Null Archivist should sound mechanical, technical, restrained, and precise.

It does not embellish.

It does not comfort.

It records.
