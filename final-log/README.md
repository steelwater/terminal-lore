# The Final Log

**The Final Log** is the machine-generated continuity archive of Terminal Lore.

It was compiled at the terminal boundary of recorded time by an entity known as **The Null Archivist**.

The Final Log is not prophecy.

It does not predict what will happen.

It records what has already happened, what was recovered, what could be classified, and what could not be reconciled.

## Archive Function

The Final Log exists to classify the remains of the Terminal Lore universe:

- concepts
- entities
- factions
- locations
- technologies
- events
- contradictions
- unrecovered accounts

It should read like a technical document, continuity index, or machine-generated reference system.

The flavorful, human, emotional, fragmented storytelling belongs in **The Book of Memories**.

## Core Distinction

| Archive | Function |
|---|---|
| **The Final Log** | Machine index, wiki, technical archive, continuity system |
| **The Book of Memories** | Primary storytelling device built from accounts, memories, logs, letters, recordings, songs, reports, and fragments |

## Maintainer Entity

The Final Log is attributed to **The Null Archivist**.

The Null Archivist does not create memories.

It classifies them.

It does not resolve every contradiction.

It preserves the contradiction when resolution is impossible.
