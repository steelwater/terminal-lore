# Canon Policy

Terminal Lore uses status labels so ideas can be explored without breaking continuity.

## Status Values

- `canon` — accepted source-of-truth lore
- `draft` — usable but still evolving
- `apocrypha` — interesting variant or abandoned branch
- `contradiction` — known conflict that needs resolution

## Entry Metadata

Each Final Log entry should begin with frontmatter:

```yaml
---
id: unique-entry-id
title: Entry Title
type: concept | entity | faction | location | event | artifact | continuity
status: canon | draft | apocrypha | contradiction
tags: []
related: []
---
```

## Final Log Rule

The Final Log explains, classifies, and indexes.

It should not become the primary storytelling device.

The Book of Memories is reserved for accounts, memories, logs, letters, recordings, songs, poems, inscriptions, and recovered media.

## No Prophecy Rule

Terminal Lore may contain warnings, forecasts, simulations, memories, theories, and machine projections.

It should not frame the Book of Memories as prophecy.
