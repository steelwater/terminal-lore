# README Style Note

The root README should feel like a terminal archive entry rather than a generic GitHub project page.

Style rules:

- No emojis or icon headings.
- Major sections may use dot-matrix ASCII banners.
- Smaller groups may use slanted ASCII banners.
- Keep prose clear and readable under the banners.
- The README should direct readers into `final-log/` for classification and `book-of-memories/` for story artifacts.
