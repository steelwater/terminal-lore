# Mobile README Check

When reviewing the rendered README on mobile, check these items:

- Do the large dot-matrix banners remain readable?
- Do the smaller slanted ASCII headings wrap too much?
- Is the repo structure section easy to scan?
- Is the Final Log / Book of Memories split clear?

If the ASCII banners are too wide, reduce major section banners to the shortest labels only:

- SYSTEM
- ARCHIVE
- FINAL LOG
- MEMORIES
- STRUCTURE
- STATUS
